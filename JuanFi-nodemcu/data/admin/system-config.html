Notifications

Get a message when a customer finishes inserting coins or abandons a session. Settings are stored on this device; actual delivery depends on network access and supported providers in this firmware build.

Telegram and public ntfy (HTTPS) need outbound internet from the device and a compatible build. A self-hosted ntfy server on your LAN can use plain HTTP (e.g. http://192.168.1.10). On public ntfy, topic names are guessable — use an unguessable topic and/or an access token.
